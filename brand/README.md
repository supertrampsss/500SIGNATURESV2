# Marque 500 Signatures

Identité du 31 octobre 2026. Les règles complètes sont dans le guide (artifact « Guide 500 Signatures »).

- `logos/` : trois pistes (A paraphe, recommandée ; B pièces ; C sceau), logotype, icône (avatar X, favicon), version une couleur. SVG à ouvrir dans un navigateur ; les textes utilisent les polices du site (`site/public/polices`, via `polices.css`) : garder le dossier dans le dépôt pour les ouvrir.
- `social/` : modèles de publication à modifier dans le navigateur (clic sur un texte) puis à capturer : citation et annonce 1200 × 675, couverture de carrousel 1080 × 1350, story 1080 × 1920, témoignage 1200 × 675.

Le modèle de témoignage contient un texte de remplacement : ne publier qu’un message réel, avec l’accord de son auteur.
