CONFIDENTIALITÉ

Vos données, simplement.

500 Signatures ne demande pas de compte pour consulter les données publiques ou utiliser les principaux outils du site.

Stockage dans votre navigateur

Certaines préférences et certaines fonctions, notamment la sauvegarde d'une partie Mandats, utilisent le stockage local du navigateur. Ces informations restent sur votre appareil tant que vous ne les effacez pas.

Publicité

Les pages principales chargent Google AdSense. Ce service peut utiliser des cookies ou des technologies similaires pour diffuser, limiter ou mesurer les annonces. Vous pouvez consulter les informations de Google sur la confidentialité et sur les technologies publicitaires.

Mesure d'audience

Le code applicatif actuel de 500 Signatures n'intègre pas d'outil tiers de mesure d'audience distinct d'AdSense.

Vos choix

Vous pouvez supprimer le stockage local depuis les réglages de votre navigateur. Les réglages publicitaires de Google permettent également de gérer certaines préférences liées aux annonces.
